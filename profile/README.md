# Second Save

Fan translations and native recompilations of games that never got a second chance.

- **Recomps:** old PC and console games rebuilt as native C for macOS, Linux and Windows.
- **Translations:** English patches for games that never left Japan, Taiwan or Korea, including the whole Super A'Can library.

No game data is ever included. Patches and recomps need your own legally obtained copy.
